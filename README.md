# ctx Homebrew tap

Homebrew packages for ctx projects.

## Install ctx CLI

```sh
brew install ctxrs/tap/ctx
```

`ctx` is the CLI for fast local search over coding-agent history.

## Install ctx ADE

For users who specifically want Homebrew, the macOS desktop app is available as
a cask:

```sh
brew install --cask ctxrs/tap/ctx-ade
```
